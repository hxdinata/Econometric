# Econometric
    Repositori ini berisi materi pendukung dari CD buku "Econometric: Runtun Waktu". Di dalamnya terdapat skrip contoh, dataset, dan catatan praktis untuk belajar metode ekonometrika runtun waktu (time series). Tujuan repo ini adalah memudahkan pembaca mengikuti contoh dalam buku dan bereksperimen dengan data nyata untuk memahami model dan teknik analisis runtun waktu.
